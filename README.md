# 浏览器工作流录制与回放（个人任务库）

把用户亲自演示过的浏览器操作变成可反复执行的自动化任务：录一次、以后随时回放，支持每次输入不同参数，也可挂定时任务（browser-workflow-recorder）。

## 项目解决什么问题

业务后台、电商平台、飞书网页版、数据系统、资讯网站里的重复操作，每次都要手动点一遍。本技能把"用户演示一遍操作"变成"可回放的自动化任务"，以后一句话就能跑，还能定时跑、换参数跑，并维护一个个人任务库统一管理。

## 主要功能

| 功能 | 说明 |
|------|------|
| 录制新流程 | 用户演示 → 参数化整理 → 用户确认 → 生成实现 → 入库 |
| 回放已录流程 | 一句话触发，按参数 schema 收集本次参数后自动执行 |
| 定时回放 | 与定时任务联动，到点自动执行库中流程 |
| 库管理 | list / get / add / update / remove 统一管理任务库 |

## 安装方法

### 方式一：豆包技能导入（推荐）

将本目录（SKILL.md + references/ + scripts/）整体导入豆包/支持技能的平台，技能名 `browser-workflow-recorder`。

### 方式二：手动放置

把目录放入用户的技能目录，确保 `scripts/library.py` 与 `references/` 保持相对路径结构。

### 要求

- 依赖已安装的 **browser-record-replay** 技能（录制/回放引擎）与 `rpa-dev-local.exe`。
- 任务库根目录：`C:\Users\<用户名>\Doubao\browser-workflows`（发布版为占位符，安装时替换为你的 Windows 用户名）。

## 使用方法

1. **录制**：说"录制操作 / 把这个流程录下来"，按对齐清单确认流程名、参数后开始演示。
2. **回放**：说"跑一下 XX 流程"，给出本次参数（或用默认值）。
3. **定时**：说"每天固定时间跑 XX"，创建定时任务并绑定库中流程。
4. **管理**：用 `scripts/library.py` 的 list/get/add/update/remove。

## 输入输出示例

**输入：** "录制操作"（用户随后演示：打开运营后台 → 选日期 → 导出报表）

**输出：** 任务已入库，给出触发例句："以后你说『跑一下每日销售数据』，告诉我日期和渠道即可自动执行；也可以让我设成每天定时跑。"

**输入：** "跑一下每日销售数据，开始日期 2026-10-13，渠道 抖音"

**输出：** 回放执行，结果以 Markdown 表格呈现（每行一条记录）。
